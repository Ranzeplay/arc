`Arc::Std::Compilation`

## Annotations

### Entrypoint

Only one function can have the annotation in each executable project. The annotation binds the annotation to this function so that the program begins from the function.

#### Format

```arc
@Entrypoint
```

#### Parameters

None.

### Export

Exports to public so external modules can use this.

#### Format

```arc
@Export
```

#### Parameters

None.

### Getter

#### Format

```arc
@Getter
```

#### Parameters

None.

### Setter

#### Format

```arc
@Setter
```

#### Parameters

None.

### Constructor

#### Format

```arc
@Constructor
```

#### Parameters

None.

### Destructor

#### Format

```arc
@Destructor
```

#### Parameters

None.

### SymbolId

Manually choose an ID for the direct symbol.

#### Format

```arc
@Symbol(const id: val int)
```

#### Parameters

None.

### DeclaratorOnly

Do not generate body.

#### Format

```arc
@DeclaratorOnly
```

#### Parameters

None.

### WithAnnotation

Bind an annotation to the group.

#### Format

```arc
@WithAnnotation
```

#### Parameters

None.

### WithAnnotationId

Bind an annotation with an ID manually chosen to the group.

#### Format

```arc
@WithAnnotationId(const id: val int)
```

#### Parameters

None.

### NoType

Do not regard the group as a type.

#### Format

```arc
@NoType
```

#### Parameters

None.

### GlobalLinked

Linked by all other compilation units automatically.

#### Format

```arc
@GlobalLinked
```

#### Parameters

None.
