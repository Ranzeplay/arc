---
title: Ginkgo Overhaul
---

We are currently overhauling the instruction set of the Arc Programming Language.
Any drafted specifications and changes will be documented here.

For the motivation, please refer to this [article](/article/instruction-set-overhaul-2605).

Circle selects the Ginkgo generator with `--ginkgo`. See
[Compiler support](/ginkgo/implementation) for supported source constructs,
[Instructions](/ginkgo/instructions) for instruction semantics, and
[Draft binary encoding](/ginkgo/instructions/encoding) for the current wire format.
The [package descriptor](/ginkgo/descriptors/pkg) documents the draft compiler
artifact. Runtime execution and the final runtime metadata ABI remain unfinished.
