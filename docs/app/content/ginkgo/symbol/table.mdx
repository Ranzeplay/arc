# Overview

The binary symbol kinds below match Circle's current [version 2
artifact](/ginkgo/descriptors/pkg). Runtime execution remains unsupported.

The symbol table starts with a `u32` record count. Each record contains a `u32`
symbol ID, a `u8` kind, and the corresponding payload, with no padding. Symbol
IDs are not positions in the table. See [Payload](/ginkgo/symbol/payload) for
record layouts.

# Symbol types

| Kind   | Name                 | Remark |
| ------ | -------------------- | ------ |
| `0x01` | Namespace            | Empty payload. |
| `0x02` | Function             | Includes group and lifecycle functions. |
| `0x03` | GroupField           | Field declaration. |
| `0x04` | DataType             | Internal or user-defined type. |
| `0x06` | Group                | Member IDs and lifecycle entries. |
| `0x07` | Annotation           | Target group ID. |
| `0x08` | Enum                 | Annotation and member IDs. |
| `0x09` | EnumMember           | Annotation IDs. |
| `0x0A` | GenericTypeParameter | Constraint type ID. |

`0x05` is the legacy constant symbol tag and is not emitted in this symbol
table. Constants are stored separately in counted, compilation-unit-local pools.
Group functions use kind `0x02`, not a separate group-function kind.
