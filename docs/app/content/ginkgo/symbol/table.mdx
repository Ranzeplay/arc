# Overview

The binary symbol kinds below describe the proposed runtime table. Circle's
current [draft artifact](/ginkgo/descriptors/pkg) instead serializes JSON symbols
with a string `Kind`; it does not emit this binary table.

A symbol table is an array containing symbols in the package.
Each symbol contains a type and corresponding payload.

# Symbol types

| Id     | Name          | Remark |
| ------ | ------------- | ------ |
| `0x01` | Namespace     |        |
| `0x02` | Function      |        |
| `0x03` | Group         |        |
| `0x04` | GroupField    |        |
| `0x05` | GroupFunction |        |
| `0x06` | DataType      |        |
| `0x07` | Annotation    |        |
| `0x08` | Constant      |        |
