This page describes a proposed runtime array layout, not the current package's
metadata or constant-pool encoding. Circle emits a [version 2 binary
artifact](/ginkgo/descriptors/pkg) whose constants are currently scalar values.
Source array indexing and iteration are not yet lowered by the Ginkgo generator.

# Array

An array in Ginkgo is a fixed size collection of elements of the same type.

An array start with a 4-byte length field, followed by the elements. The length field is the number of elements in the array, not the number of bytes.

```
+------------------+-----------+-----------+-----+
| Length (4 bytes) | Element 1 | Element 2 | ... |
+------------------+-----------+-----------+-----+
```
