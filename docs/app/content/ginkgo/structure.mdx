This page describes a proposed runtime layout. The current compiler artifact
stores metadata and constant pools in [JSON](/ginkgo/descriptors/pkg), not this
binary array representation. Source array indexing and iteration are not yet
lowered by the Ginkgo generator.

# Array

An array in Ginkgo is a fixed size collection of elements of the same type.

An array start with a 4-byte length field, followed by the elements. The length field is the number of elements in the array, not the number of bytes.

```
+------------------+-----------+-----------+-----+
| Length (4 bytes) | Element 1 | Element 2 | ... |
+------------------+-----------+-----------+-----+
```
