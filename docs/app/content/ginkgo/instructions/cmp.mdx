---
title: 'Comparison'
---

Every comparison writes a boolean result and has a trailing flag byte:

- `last_use_src_l`: Last use of the left source register (bit 0).
- `last_use_src_r`: Last use of the right source register (bit 1).
- `use_dest_next`: Destination used immediately after definition (bit 2).
- `cmp_ref`: Reference comparison (bit 3).

The compiler sets `cmp_ref` only for reference equality and inequality. Reference
ordering is unspecified even though the instruction models expose the flag.
Current lowering requires matching operand types; overloaded operator resolution
is not implemented. See [Draft binary encoding](/ginkgo/instructions/encoding).

# Equal

```
eq src_l, src_r, dest, flags
```

Expresses the intention to set $dest = (src_l = src_r)$ where all operands are implicit variables.

Semantics follow the data type of $src_l$; an overloaded operator will be used if present.

## Flags

- `cmp_ref`: Use reference comparison instead of value comparison.
