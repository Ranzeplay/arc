See [Draft binary encoding](/ginkgo/instructions/encoding) for operand widths and
flag bits. Overloaded operators describe intended semantics; the current Ginkgo
generator does not resolve operator overloads.

# Load from Constant Pool

```
ld_const idx, dest, flags
```

Performs $dest = const_pool[idx]$ where $dest$ is an implicit variable.

Operation follows the data type of $dest$,
use an overloaded operator if one exists.

## Flags

- `ld_const_ref`: Load reference from constant pool instead of value.
- `usage_hint`: $dest$ is loaded immediately after definition, can be used for optimization.

# Load Immediate Integer

```
ld_int value, dest, flags
```

Performs $dest = value$ where $dest$ is an implicit variable.

Value will be casted to the data type of $dest$ if necessary.

Operation follows the data type of $dest$,
use an overloaded operator if one exists.

## Flags

- `usage_hint`: $dest$ is loaded immediately after definition, can be used for optimization.

# Load Floating-point Constant

```
ld_float value, dest, flags
```

Performs $dest = value$ where $dest$ is an implicit variable.

`value` is an IEEE 754 binary64 immediate. Decimal source literals instead use the
typed constant pool to preserve precision. Flag bit 0 is `usage_hint`.

Operation follows the data type of $dest$,
use an overloaded operator if one exists.

# Copy

Flag bit 0 is `last_use_src`; bit 1 is `usage_hint`.

```
copy src, dest, flags
```

Performs shallow clone $dest = src$ where all operands are implicit variables.

Operation follows the data type of $dest$,
use an overloaded operator if one exists.

## Flags

- `usage_hint`: $dest$ is loaded immediately after definition, can be used for optimization.

# Initialize Object

```
init_obj type_idx, dest, dim, flags
```

Allocates an object of type symbol ID `type_idx` with dimension `dim` into
register `dest`. The type operand is a symbol ID, not a symbol table position.
Allocation alone does not invoke a constructor; supported group construction
emits a separate lifecycle call. See [Compiler support](/ginkgo/implementation).

## Flags

- `usage_hint`: $dest$ is loaded immediately after definition, can be used for optimization.

# Load Field from Object

```
ld_field src, dest, field_id, flags
```

Performs $dest = src.field\_id$ where `src` and `dest` are registers and
`field_id` is a field symbol ID.

## Flags

- `last_use_src`: Whether this is the last use of the source register.
- `usage_hint`: $dest$ is loaded immediately after definition, can be used for optimization.

# Store Field to Object

```
st_field src, dest, field_id, flags
```

Performs $dest.field\_id = src$ where `src` is the value register, `dest` is the
object register, and `field_id` is a field symbol ID.

## Flags

- `last_use_src`: Whether this is the last use of the source register.
- `usage_hint`: $dest$ is loaded immediately after definition, can be used for optimization.
