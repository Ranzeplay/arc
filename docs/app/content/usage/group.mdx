---
title: Group
---

A group is a way to combine many data and multiple functions.

## Syntax

```arc
<accessibility> group <name>
{
    <members>
}
```

## Example

```arc
public group Bar
{
      @Getter
      public field var bitem: val int;

      public func getFoo(var self: ref Bar, var addend: val int): val Foo
      {
         var foo: val Foo;
         foo.fitem = self.bitem + addend;

         return foo;
      }
}
```

## Members

### Field

The syntax of defining a field is similar to declaring data in a function.

```arc
<accessibility> field <mutability> <name>: <memory storage> <type>;
```

#### Annotations

##### Getter

Automatically generate a getter function.

##### Setter

Automatically generate the assignment function.

##### Accessor

Do the work of `Getter` and `Setter`.

### Function

The syntax of defining a function is the same as defining an individual function, and it behaves just like an individual function.

### Method

An instance method declares `self` as its first parameter, with the enclosing
group's scalar type. A group function without `self` does not require an instance.

`self` is a receiver expression, not an ordinary local identifier. It is only
available inside an instance method and cannot be shadowed by a local variable.

Both of these calls invoke the same concrete method (inside `namespace Example`):

```arc
call item.update(42);
call [Example::Item].update(item, 42);
```

The qualified form supplies the receiver explicitly as its first argument. The
compiler checks the receiver separately from the method's remaining parameters;
both forms use the same argument-zero calling convention. Qualification does not
provide interface or virtual dispatch, which is not currently implemented.

In Ginkgo, constructors initialize the allocated `self` and return `none`. The
`new` expression produces the allocated object, not the constructor's return value.

## Annotations

#### WithAnnotation

The group can be used as an annotation.

#### NoType

The group will not be used as a type, so it cannot have any methods at the same time.
